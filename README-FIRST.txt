欣赏相册集 · 使用说明
========================================

【最简单的用法】
双击 start-album.bat
（就是那个名字带 .bat 的文件，Windows 会显示成「Windows 批处理文件」）

不用联网、不用安装任何软件，浏览器会自动打开相册。
用完把那个命令行窗口关掉就行。


【三个要注意的地方】

1. 不要直接双击 album.html。
   那样会白屏或报错 —— 浏览器不允许 file:// 页面使用本地数据库，
   必须通过 start-album.bat 起的本地服务打开。

2. 第一次打开是空相册，看不到别人的照片。
   点右上角 ＋ 导入图片，或者直接把图片拖进窗口。
   数据只存在你自己的浏览器里，别人看不到你的。

3. 清浏览器数据 = 相册全部丢失。
   请偶尔点右上角 ⋯ →「⬇ 备份整个相册」，
   把生成的 json 文件存到网盘或 U 盘里。


【手机上怎么用】

方式一：在线链接（最省事，推荐）
让分享给你的人发在线链接（github.io 那个地址），
手机浏览器打开后，在菜单里选「添加到主屏幕」就能当 App 用。

方式二：同一 WiFi，用电脑临时开给手机（不用上传、不用联网）
1. 电脑和手机连同一个 WiFi
2. 电脑上双击 start-album-phone.bat（注意是带 -phone 的那个）
3. 窗口里会打印一条 http://192.168.x.x:8080/album.html 的地址
4. 手机浏览器输入这条地址即可
5. 如果 Windows 弹出防火墙提示，勾选「专用网络」并允许
6. 用完关掉电脑上的黑色窗口
注意：这种方式数据存在手机浏览器里，和电脑上的相册不互通；
      内网地址不是安全连接，不能「添加到主屏幕」，属正常现象。


【如果打不开】
· 窗口一闪就没了 → 右键 start-album.bat →「以管理员身份运行」
· 提示端口被占用 → 关掉其他占用端口的程序，再双击一次
· 浏览器一直转圈 → 关掉窗口重新双击一次
